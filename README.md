# FutureTech Landing Page

A modern, sleek, fully responsive landing page built with semantic HTML5, modern Tailwind CSS, dark glassmorphism aesthetic, and dynamic vanilla JavaScript.

## Features
- **Hero Section**: Canvas-based dynamic particle background with futuristic call-to-action buttons.
- **About Section**: Sleek architecture highlighting smart technologies and quantum-level performance metrics.
- **Features Section**: Interactive cards with glowing hover states (AI Integration, High Performance, Cloud Sync).
- **Contact Form**: Real-time form validation with a modern visual feedback popup modal.
- **Responsive Layout**: Sticky navigation bar with mobile drawer toggle menu.

## Tech Stack
- HTML5 & CSS Variables
- Tailwind CSS (CDN)
- Vanilla JavaScript (ES6+)
- FontAwesome Icons
